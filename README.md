# ecoQuest

*The free, fun, and effective way to learn how to reduce waste!*

## Overview

**ecoQuest** is an interactive web-based educational platform designed to make learning about sustainability and waste reduction engaging and enjoyable. Through gamified learning experiences including quizzes, memory card games, and puzzle challenges, users can enhance their environmental knowledge while having fun.

## Features

- **Interactive Games**: Multiple game modes to make learning engaging
  - **Quiz Mode**: Test your knowledge about environmental practices and sustainability
  - **Memory Cards**: Match cards to learn about eco-friendly concepts
  - **Puzzle Games**: Solve puzzles while learning about waste reduction
  - **Flip Game**: Card-flipping challenges with environmental themes

- **Educational Content**: Comprehensive information about waste reduction and sustainable practices

- **User-Friendly Interface**: Clean, modern design with intuitive navigation

- **Eco-Friendly Mission**: Learn practical tips to reduce waste and live sustainably

## Getting Started

### Prerequisites
- Any modern web browser (Chrome, Firefox, Safari, Edge)
- No installation required!

### How to Use

1. **Visit the Landing Page**: Start at `index.html` to access the main menu
2. **Click "GET STARTED"**: Begin your eco-learning journey
3. **Choose a Game Mode**:
   - Navigate to Cards.html for memory card matching
   - Try Quiz.html for sustainability quizzes
   - Challenge yourself with Puzzle.html for puzzle games
   - Play flip.html for card-flipping challenges
4. **Learn & Earn**: Complete challenges and expand your environmental knowledge!
